## Map tiles

The map view loads raster tiles from `tile.openstreetmap.org`. Map data
© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) (ODbL).
Please respect the [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/);
this app is meant for personal, low-volume use. For heavier use, point the tile URL in
`public/app.js` to a tile provider you are allowed to use.
